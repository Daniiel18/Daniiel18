## 🚀 Featured projects

### 💍 [Lazo de Oro](https://github.com/Daniiel18/plataforma-bodas) · [live](https://lazodeoro.vercel.app)

A free SaaS for wedding websites. Couples design their invitation step by step without an account, sign in with Google or an emailed code to publish it, and follow every reply from their dashboard; guests get a fast, bilingual, mobile-first invitation with RSVP, music, a 3D gallery and a gift box.

`Next.js 16` `React 19` `TypeScript` `Supabase (Postgres + RLS)` `Tailwind CSS 4` `Web Push` `Vercel`

- Row Level Security on every table, server-only RPCs for guests, cached invitations refreshed on save
- Builder that works offline in the browser (IndexedDB), photo framing editor, Excel export
- Back office with conversion funnel, free-tier usage, error log, audit trail and a daily lifecycle job

### ✈️ [SimFleet](https://github.com/Daniiel18/msfs-addons-browser) · [live demo](https://daniiel18.github.io/msfs-addons-browser/)

An all-in-one Windows companion for Microsoft Flight Simulator 2020 & 2024: browse, download and install addons into the Community folder, then track your flying with a logbook, analytics, an airline economy and achievements.

`Rust` `Tauri 2` `React` `TypeScript` `BitTorrent (librqbit)` `MapLibre`

### 🗺️ [Scenery Addons Browser](https://github.com/Daniiel18/SceneryAddonsBrowser)

The desktop app that started SimFleet: search scenery by airport, download it with a built-in torrent engine and install it in one click, with automatic updates.

`C#` `.NET 8` `WPF` `MonoTorrent` `Velopack`

### 🧾 [Sistema de Ventas](https://github.com/Daniiel18/SistemaVentas) · [live](http://sistemaventas-daniel.runasp.net)

A point-of-sale and inventory web app: sales with PDF receipts, products with photos, users and roles, reports to Excel and a sales dashboard, in a layered ASP.NET Core architecture.

`ASP.NET Core MVC` `.NET 10` `C#` `Entity Framework Core` `SQL Server` `QuestPDF`
